San Andreas Audio Toolbox PC/PS2 GUI — Changelog

v2.1
- Fixed the fundamental GTA SA PS2 stream packing format. The prior encoder emitted alternating L/R frames rather than the game's channel-block layout.
- Creates both synchronized stream variants: 750 Hz mini audio (0x800 bytes/channel) and full audio (0x10000 bytes/channel) in 0x21000-byte chunks.
- Sets the start flag independently on the first frame of each channel.
- Rebuilds from the physical packed payload so the lookup table reflects the packed size, not the temporary raw ADPCM size.
- Updates per-channel mini/full byte counts and corresponding 750 Hz / 24,000 Hz fields in the 8,068-byte type-4 header.
- Adds a format-specific self-test for channel block offsets, frame flags, and writable header updates.
- Updated README to document the format caveat and require an in-game PCSX2 playback test.

v2.0
- Incorrectly treated the 24,000 Hz stream-header value as the only problem and emitted an unwrapped stereo ADPCM payload. Replaced by the proper chunked stream layout in v2.1.

v1.9
- Fixed archive detection to recognize GTA San Andreas PS2 stream headers as well as standalone VAGp containers.
- Corrected the misleading “no VAGp headers” status for radio PAKs whose entries use the GTA SA 8,068-byte stream header.

v1.8
- Initially changed PS2 radio replacement payloads to 32,000 Hz; this was not a validated fix.
